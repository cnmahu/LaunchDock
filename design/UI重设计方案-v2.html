启坞 LaunchDock — 云母材质 + 设置界面重构

v2 修正：目标效果的关键不是暖粉色，而是 Windows 云母（Mica）材质——色调由系统按桌面壁纸取样。我们的云母效果不对，根因是窗口上叠了一层半透明白色蒙版。设置界面整体重排为「左导航 + 每条设置独立卡片」。

改动 1：ApplyMaterial 材质逻辑 改动 2：SettingsWindow 布局重构 仅样式与布局，不动功能逻辑 2026-11-15

01为什么我们的「云母」和人家不一样

云母是系统 DWM 直接在窗口背景上绘制的，色调来自壁纸取样（所以 LaunchDock 截图偏暖粉，是人家壁纸的颜色）。我们的代码在材质之上又画了一层 72% 不透明的白色，把云母盖住了。

壁纸 / 云母底
现状：云母被白膜盖住ApplyMaterial() 中 baseAlpha = 0.72，即 Background = 72% 不透明白。云母纹理只剩 28% 透出，看起来就是发白、发灰的亚克力。
壁纸 / 云母底
目标：云母直接透出选「云母」时 Background = Transparent，不在材质上叠色，DWM 画的云母原样显示，色调随壁纸。卡片、导航等 UI 层自己带白底，可读性不受影响。
落地改动（LauncherWindow.axaml.cs · ApplyMaterial，AppLibraryWindow 同理）：材质为 Mica 时背景改透明；「面板不透明度」滑块只作用于亚克力模式（云母本身不透明，滑块对它无意义）；亚克力模式保留当前叠色逻辑。

03设置界面 — 从「杂乱无章」到 LaunchDock 式排布

现状问题与新排布规则对照：

现状的问题

  • 「概要 / 行为 / 安全」三页是纯堆叠，没有卡片容器，视觉松散
  • 同一页里 CheckBox、ComboBox、Button 混排，没有统一的行结构
  • 有的页有页标题、有的没有；间距一会儿 4 一会儿 12
  • 「外观」页一张大卡里塞 6 行，主次不分

LaunchDock 式规则（方案）

  • 每条设置 = 一张独立白卡片：左图标 + 标题/一行说明 + 右侧控件
  • 所有页统一：页标题 15px + 卡片间距 12px + 卡片内边距 13/16
  • 开关、下拉、按钮、滑块统一样式（暖棕强调色）
  • 导航重排为 6 页：常规 / 外观 / 偏好 / 唤出与收起 / 安全与隐私 / 维护
