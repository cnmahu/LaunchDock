启坞 LaunchDock — 暖粉米色系重设计

以「暖米白 + 雾粉」的视觉语言为基准，覆盖启动板主窗口与设置窗口。本页面为纯静态预览，未改动任何源码；确认后再落地到 Avalonia XAML。

范围：LauncherWindow / SettingsWindow / AppStyles 仅样式层改造，不动功能逻辑 2026-11-15

01设计令牌 Tokens

整套视觉只围绕一组暖色令牌展开，落地时直接写入 Avalonia 的 ResourceDictionary，深浅色切换只需替换令牌值。

02启动板主窗口 LauncherWindow

保留现有结构（标题栏 / 搜索 / 分组标签 / 图标网格 / 便签），只替换视觉：暖米白底、暖棕下划线选中态、图标卡片化悬停。可点击标签与图标预览交互。

启坞 LaunchDock
改动要点：① 窗口背景由纯白改为 #FBF2EE（AcrylicBlur 材质下透出暖调）；② 标签选中用暖棕短下划线，替代中性灰；③ 图标无图标时的首字符色块改用暖色系板；④ 悬停态统一 rgba(138,106,92,.08)。

03设置窗口 SettingsWindow

左侧导航 + 右侧卡片区。导航选中项带 3px 暖棕指示条；每个设置项是独立白卡片；开关、下拉、滑块全部换成暖棕系。点击左侧导航可切换页面预览。
